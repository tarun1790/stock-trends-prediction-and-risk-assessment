Approach 1: Continuous Representation [0, 1]

Raw indicator values computed via mathematical formulas (Table 10) and normalized via MinMax scaling into the range $[0, 1]$: $$x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$

• Features: Non-stationary continuous values

• Baseline Paper F1: ~68% (Traditional ML) / ~86% (DL)

Approach 2: Binary Trend-Deterministic (+1 / -1)

Converts continuous oscillators into directional signals (+1 Upward / -1 Downward) based on indicator nature and momentum crossovers (Section II-B):

• SMA/WMA: +1 if Close ≥ MA else -1

• RSI: -1 if >70, +1 if <30, else sign(ΔRSI)

• Baseline Paper F1: ~85% (Traditional ML) / ~90% (DL)
